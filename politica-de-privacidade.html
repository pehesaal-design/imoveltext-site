ImóvelStudio

Política de Privacidade

Última atualização: 10/07/2026

1. Quem somos

O ImóvelStudio (imovelstudio.com.br) é uma plataforma que utiliza inteligência artificial para gerar anúncios, imagens e materiais de marketing para corretores e imobiliárias.

O ImóvelStudio é operado por Pedro Henrique Santos Almeida, com sede em Salvador, Bahia, doravante denominado "ImóvelStudio", "nós" ou "controlador dos dados".

Para qualquer dúvida sobre esta política ou sobre seus dados pessoais, entre em contato: suporte.imovelstudio@gmail.com

2. Quais dados coletamos

2.1. Dados de cadastro e conta
Ao criar sua conta via login com Google, coletamos: nome, endereço de e-mail e foto de perfil (conforme fornecidos pelo Google).

2.2. Dados de uso da plataforma
Informações que você insere para gerar anúncios: dados do imóvel (endereço, características, preço, fotos), textos e imagens gerados pela IA a partir dessas informações.

2.3. Dados de pagamento
Não armazenamos dados de cartão de crédito. O processamento de pagamentos é feito integralmente pelo Stripe, que coleta e processa esses dados sob sua própria política de privacidade. Recebemos apenas a confirmação de que o pagamento foi realizado e o status da sua assinatura.

2.4. Dados de leads (visitantes do e-book gratuito)
Se você baixar nosso material gratuito ("Como Criar um Instagram Imobiliário Lucrativo"), coletamos nome e e-mail para envio do material e eventuais comunicações relacionadas.

2.5. Dados de navegação
Podemos coletar informações técnicas básicas (tipo de navegador, páginas visitadas) para melhorar o funcionamento do site.

3. Como usamos seus dados

Utilizamos os dados coletados para:

  • Criar e manter sua conta na plataforma;
  • Gerar os anúncios, textos e imagens solicitados por você, incluindo o envio de informações do imóvel para o provedor de inteligência artificial (OpenAI) processar a geração de conteúdo;
  • Processar pagamentos e gerenciar sua assinatura;
  • Enviar comunicações sobre sua conta, cobranças ou atualizações relevantes do serviço;
  • Enviar o e-book gratuito e conteúdos relacionados, caso você tenha se cadastrado para recebê-lo;
  • Cumprir obrigações legais e fiscais.

Não vendemos seus dados pessoais a terceiros, e não os utilizamos para fins diferentes dos descritos acima sem seu consentimento.

4. Com quem compartilhamos dados

Para operar o serviço, compartilhamos dados com os seguintes prestadores, cada um responsável pela proteção dos dados que processa:

Empresa Finalidade
Google Autenticação de login (OAuth)
OpenAI Geração de textos e imagens via inteligência artificial
Stripe Processamento de pagamentos e assinaturas
Supabase Armazenamento de dados e infraestrutura de banco de dados
GitHub Pages Hospedagem do site

Esses dados podem ser processados em servidores fora do Brasil, sempre respeitando padrões de proteção compatíveis com a LGPD.

5. Base legal (LGPD)

Tratamos seus dados com base nas seguintes hipóteses legais previstas na Lei Geral de Proteção de Dados (Lei nº 13.709/2018):

  • Execução de contrato: para fornecer o serviço que você contratou;
  • Consentimento: para envio de comunicações de marketing e do e-book gratuito;
  • Legítimo interesse: para melhorias no serviço e prevenção a fraudes;
  • Cumprimento de obrigação legal: para fins fiscais e contábeis.

6. Seus direitos como titular dos dados

De acordo com a LGPD, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados;
  • Acessar os dados que temos sobre você;
  • Corrigir dados incompletos, inexatos ou desatualizados;
  • Solicitar a exclusão dos seus dados (exceto quando houver obrigação legal de retenção, como dados fiscais);
  • Solicitar a portabilidade dos seus dados a outro fornecedor;
  • Revogar seu consentimento a qualquer momento;
  • Obter informações sobre com quem compartilhamos seus dados.

Para exercer qualquer um desses direitos, escreva para suporte.imovelstudio@gmail.com. Responderemos em prazo razoável, conforme previsto em lei.

7. Retenção de dados

Mantemos seus dados enquanto sua conta estiver ativa. Após o cancelamento, podemos manter alguns dados por período adicional para cumprir obrigações legais (como registros fiscais de pagamento) ou para resolver eventuais disputas.

8. Segurança

Adotamos medidas técnicas razoáveis para proteger seus dados contra acesso não autorizado, perda ou alteração, incluindo controle de acesso via autenticação e políticas de segurança em nível de banco de dados (RLS).

Nenhum sistema é 100% seguro, mas nos comprometemos a agir rapidamente em caso de incidente de segurança que envolva seus dados, conforme exigido pela LGPD.

9. Menores de idade

O ImóvelStudio é destinado a profissionais maiores de 18 anos. Não coletamos intencionalmente dados de menores de idade.

10. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações significativas serão comunicadas por e-mail ou aviso no site. A data da última atualização está sempre indicada no topo deste documento.
